# Mars Colony Buddies

Create a colourful, interactive 2D browser game called Mars Base Buddies according to the attached PHASE 1 specification.

Follow every requirement in PHASE 1: BUILD THE FOUNDATION OF MARS BASE BUDDIES:
- Educational space exploration and colony-management game for kids 7–12.
- Actual playable 2D top-down game on full-screen HTML Canvas (100vw, 100dvh/100vh fallback, no scrolling, no dashboard cards/padding).
- Character selection screen ("Choose Your Astronaut") featuring Boy Astronaut and Girl Astronaut with detailed designs, hairstyle/face visible through helmet, previews, start button, and persistence (localStorage) plus option to switch/restart.
- Rich 2D top-down Mars environment: vibrant Martian terrain, craters, rocks, futuristic colony modules, solar panels, comms antenna, research equipment, lander spacecraft.
- Smooth astronaut movement (WASD/arrows on desktop, responsive touch D-pad/joystick on mobile) with 4-direction animations and smooth camera follow across an explorable map.
- HUD overlays: Top-left title & Sol count; Top-center resources (Energy, Oxygen, Water, Food); Top-right mission objective ("Explore your new Mars colony"); Bottom-right PIP companion dialogue and portrait welcoming the astronaut.
- Responsive, playable on mobile and desktop.
